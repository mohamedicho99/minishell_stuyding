
for the return type function, we don't need to pass the entire struct to it

we just need to give it the string,

because the function that'll create the token will need the string of chars
	we get from str->str, not the whole thing.

	for example, if we get "ls -la || cat file.txt > yo.txt"
		the first string we get is "||" and that's all it needs to declate
			that as a pipe token

			NOTE: we don't get the "ls" first because it's clearly a word
				token and that's already been handled by another function
